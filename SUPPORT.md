# Support Policy

Welcome to the support guide for the YouTube Cognitive Firewall.

## Support Channels

### 1. GitHub Issues
- If you encounter a bug, have a feature request, or have a question, please search the existing [GitHub Issues](https://github.com/L9G9N0/youtube-cognitive-firewall/issues) before opening a new one.
- Use the appropriate template (Bug Report, Feature Request, or Question) when creating an issue.

### 2. Discussions
- For open-ended questions, architectural feedback, or general discussions about cognitive focus strategies, please join our [GitHub Discussions](https://github.com/L9G9N0/youtube-cognitive-firewall/discussions) board.

---

## Response Times

- This project is maintained by a core engineering team in their free time.
- We aim to review all new issues within 72 hours.
- Pull Requests with passing builds and descriptive checklists are prioritized.
