# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-06-19
### Added
- Initial Chrome Extension setup using React (v19) and TypeScript.
- Build configuration utilizing Vite (v8) and Rollup for separate popup, content, and background files compilation.
- Empty module shells for content scripts, background workers, and popup dashboard.
- GitHub repository standards including contributing guidelines, security policies, and issue templates.
